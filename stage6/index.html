How this was drawn The pink stripes are a CSS gradient. The wavy card frame in 13 and 14 and the wavy edge under the 15 photo are SVG paths generated at the measured size, so their waves never stretch. The note card in 14 sits in a box with the bitmap's own proportions and the text is real text on top of it. The garden photo is cropped with object-fit: cover, never resampled to a new shape, and was re-encoded so it carries no metadata. Icons are sized by CSS height. Each section is a size container, so it reflows at about 440 px: the gifts card stacks, the surprise cluster turns into a column. Typography warning Norican, Anton, DM Mono and Anonymous Pro are loaded from Google Fonts. Offline they fall back to system faces and the page looks wrong. Judge the type only on the deployed preview.
