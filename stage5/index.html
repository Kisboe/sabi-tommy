How this was drawn The menu's stripes are a CSS gradient, not 11.01. The wavy card border is an SVG path regenerated at the card's measured size whenever it changes, so the wobble keeps its amplitude in both languages and at any width; 11.02 is not used. The rays beside the heading and the wavy underline are inline SVG in fixed viewBoxes — 11.04/11.05 are RGB files with a baked checkerboard. Illustrations, stars, leaves and the figures are sized by CSS height (the figures by width, height auto, at their own aspect). The five menu illustrations were re-keyed from source with the white fill removed, per DESIGN.md. Below about 420 px the menu rows stack, illustration above text. Typography warning Norican, Caveat Brush, DM Mono and Anonymous Pro are loaded from Google Fonts. Offline they fall back to system faces and the page looks wrong. Judge the type only on the deployed preview.
