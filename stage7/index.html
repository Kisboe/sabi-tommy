How this was drawn The stripes in all three panels are CSS gradients. The FAQ sign is the template's frame bitmap (16.04), keyed and cropped to its own bounds and sized by width with height auto, so it keeps its aspect ratio. The heading is live text laid over the oval. The accordion uses native <details>/<summary>, so it works with the keyboard and screen readers without any script. The chevrons, hearts, button sprigs and the submit button's double border are inline SVG or CSS. Icons, stars and the wax stamp are sized by CSS height. The form uses real fieldset/legend groups, so the choice cards are real radios that keep keyboard focus. Switching language keeps the open FAQs and everything typed into the form. Below 460 px, container queries stack the choice cards and the allergen grid. Stars 16.02 (a dark eight-point sparkle) and 18.01 (a pink line sparkle) don't match the watercolour stars in either mockup, so the watercolour 16.01 and 18.02 are used instead. The clock and bell icons (17.02, 17.05) belong to mockup lines that have no copy, so they are not used. Typography warning Norican, Anton, DM Mono, Caveat Brush and Anonymous Pro are loaded from Google Fonts. Offline they fall back to system faces and the page looks wrong. Judge the type only on the deployed preview.
